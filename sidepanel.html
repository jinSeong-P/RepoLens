암호화 프리셋 저장소를 확인하는 중…

마스터 비밀번호 만들기

프리셋을 잠그고 다시 열 때 사용할 비밀번호입니다. RepoLens는 이 비밀번호를 저장하거나 외부로 보내지 않습니다.

12자 이상을 권장합니다. 브라우저를 닫거나 직접 잠그면 다시 입력해야 합니다.

복구할 수 없습니다. 마스터 비밀번호를 잊으면 저장된 프리셋, API 키, GitHub 연결을 해독할 수 없으며 저장소를 초기화해야 합니다.

프리셋 저장소가 잠겨 있습니다

마스터 비밀번호로 잠금을 해제해야 저장된 연결을 불러오거나 수정할 수 있습니다.

비밀번호는 잠금 해제에만 사용되며 저장되지 않습니다.

마스터 비밀번호를 잊은 경우 복구할 수 없습니다. 초기화하면 암호화된 프리셋이 모두 삭제됩니다.

보관함이 열려 있습니다

아래 AI 연결 카드에서 프리셋을 선택하거나 새 연결을 저장할 수 있습니다.

AI 연결 프리셋

설정 필요

엔드포인트, 모델, API 키를 한 묶음으로 암호화해 저장하고 분석에 사용합니다.

선택하면 편집기에만 채워집니다. 아래 ‘저장하고 사용’을 누를 때 활성 연결이 바뀝니다.

API 제공자나 용도를 구분할 수 있는 이름을 사용하세요.

/chat/completions는 자동으로 붙습니다. 외부 서버는 HTTPS만 허용합니다.

모델 목록을 임의로 추측하지 않습니다. 정확한 ID를 입력해 주세요.

프리셋 저장 시 암호화해 보관합니다. 잠금 해제 중인 활성 연결만 Chrome의 신뢰된 세션 영역에서 사용됩니다.

연결 테스트는 작은 AI 요청을 보내므로 소량의 사용량이 발생할 수 있습니다. GitHub 코드는 보내지 않습니다.
